# البنية المقترحة (Architecture)

هذا تصور أولي قابل للنقاش، وليس تصميمًا نهائيًا.

```
[ناقلة + جهاز GPS/حساسات] --> [بوابة استقبال البيانات] --> [قائمة رسائل]
                                                              |
              +-----------------------+-----------------------+
              |                       |                       |
     [محرك قواعد المخاطر]    [تحليل وذكاء اصطناعي]    [قاعدة بيانات المسارات]
              |                       |                       |
              +-----------> [خدمة التنبيهات] <----------------+
                                      |
        +-----------+-----------+-----+-----+-------------+
     [المرور]   [الإسعاف]  [الحماية المدنية]  [شركة النقل]  [الجهة الرقابية]
                       (لوحة تحكم واحدة + تطبيق للسائق)
```

## المكونات

1. **أجهزة التتبع:** GPS مع سرعة واتجاه، واختياريًا حساسات (حرارة، ضغط، فتح الحاوية).
2. **بوابة الاستقبال:** تستقبل المواقع كل 5 إلى 30 ثانية، وتتحقق من صحتها وتخزنها.
3. **محرك القواعد:** قواعد واضحة وقابلة للتفسير (سرعة، مسار، توقف، ساعات قيادة، فحص المركبة، طقس).
4. **التحليل والذكاء الاصطناعي:** مرحلة لاحقة. اكتشاف النقاط السوداء، والتنبؤ بالمخاطر، وكشف السلوك الشاذ. يبدأ بعد توفر بيانات حقيقية.
5. **خدمة التنبيهات:** تحدد مستوى الخطر (منخفض، متوسط، عالٍ، حرج) وتوجّه التنبيه للجهة المناسبة وتسجل الاستجابة.
6. **لوحة التحكم:** خريطة حية، قائمة الناقلات الأعلى خطرًا، سجل الحوادث والتنبيهات.
7. **الربط بين الجهات:** واجهات برمجية (API) موحدة، وصلاحيات لكل جهة.

## مبادئ

- **الخصوصية والأمان:** بيانات المواقع حساسة. صلاحيات بحسب الدور، وتشفير، وسجل تدقيق.
- **التفسير:** كل تنبيه يوضح سببه.
- **تقليل الإنذارات الكاذبة:** حتى لا يتجاهلها الناس.
- **العمل مع ضعف الشبكة:** تخزين مؤقت على الجهاز وإرسال لاحق.
- **مفتوح المصدر:** حتى يراجعه الخبراء ويطوّره الجميع.
